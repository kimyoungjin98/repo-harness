# 디자인 시스템

## 개요

- 모노레포에 프론트엔드 프로젝트가 있거나 단일 프로젝트인데 프론트엔드 프로젝트일 경우에 필요
- 디자인 시스템이 지정되지 않았을 경우 사용자에게 지정 요청
- 사용자가 직접 구현을 지시하였을 경우 에이전트가 직접 구현

## 규칙

- 타이포그래피(Typography)
- 컬러(Color)
- 크기(Size)
- 둥글기(Rounded)
- 그림자(Shadow)
- 레이아웃(Layout)

## 공통

- 규칙을 참조하여 디자인 시스템 지정
- (직접 구현일 경우) `shadcn`, `radix-ui` 컴포넌트 사용
